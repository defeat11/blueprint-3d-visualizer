# blueprint-3d-visualizer

[English](README.en.md)

**ترسم توزيع الغرف على لوحة 2D، فيخرج برومبت معماري حتمي جاهز للصق في Google AI Studio.**

محرر مخططات يعمل في المتصفح ويبني البرومبت من إحداثياتك مباشرة، بلا نموذج لغوي وسيط. مشروع من منطقتين فقط يتحول إلى برومبت من 171 سطراً و10,742 حرفاً. حجم الكود 3,796 سطر TypeScript في 12 ملفاً.

## المشكلة

نماذج توليد الصور تتعامل مع الوصف الحر بتساهل. تطلب 3 غرف فترسم 5. تضع مكتباً في الزاوية الشمالية الغربية فيظهر في المنتصف. وإذا مررت المخطط عبر نموذج لغوي ليصيغ البرومبت، أعاد كتابة القياسات بتصرفه. النتيجة: كل توليد يعطي توزيعاً مختلفاً عن مخططك الفعلي.

## كيف يشتغل

1. ترسم المناطق على لوحة Fabric.js شبكية، بسحب وتدوير ينطبق على شبكة 15 درجة.
2. تحدد لكل منطقة نوعها من 13 نوع غرفة، ونوع القاطع، وطراز الأثاث، والميزات.
3. المحوّل يحسب مركز كل منطقة بالمتر، وحدودها، واتجاهها، وقطاعها المنطقي (north-west / central / ...).
4. `promptBuilder.ts` — وهو 913 سطراً — يجمّع البرومبت النهائي من هذه البيانات نصياً.
5. تنسخ البرومبت إلى المحرك الهدف، أو تصدّر المخطط PNG، أو تولّد سكريبت Python كاملاً.

يدعم 5 محركات إخراج:

| المحرك | صيغة الإخراج |
|---|---|
| Nano Banana (Gemini 2.5 Flash Image) | برومبت + سكريبت Python جاهز |
| Midjourney v6 | برومبت مع أعلام `--ar --stylize --no` |
| DALL-E 3 | برومبت نصي |
| Unreal Engine 5 | وصف مشهد archviz |
| Octane Render | وصف مشهد archviz |

### مخرج حقيقي

تشغيل المحوّل على مشروع من منطقتين (مكتب تنفيذي + غرفة اجتماعات) في مساحة 20×12 متراً:

```
PROMPT_LINES=171
PROMPT_CHARS=10742

ASCII floor diagram (each cell ≈ 0.4m wide; this is a guide for placement):

```

## أهم قرار في التصميم

**المشكلة:** نموذج الصور ينجرف عن المخطط، ونموذج لغوي وسيط يزيد الانجراف بإعادة الصياغة.

**القرار:** بناء حتمي محلي 100%، مع تكرار نفس التوزيع في 5 تمثيلات داخل البرومبت الواحد:

| التمثيل | ماذا يثبّت |
|---|---|
| وصف نثري لكل منطقة | النوع والأثاث والاتجاه والقطاع |
| مخطط أرضية ASCII | الموقع النسبي بصرياً، خلية ≈ 0.4 متر |
| إحداثيات الزوايا الأربع | الحدود الدقيقة بالمتر لكل منطقة |
| مصفوفة تجاور | أي منطقتين تتشاركان جداراً (سماحية 0.4 متر) |
| كتلة JSON | البيانات الخام كمرجع نهائي |

**التكلفة:** برومبت طويل (10,742 حرفاً لمنطقتين فقط)، وكود بناء ضخم (913 سطراً لملف واحد).

**العائد:** القياسات لا تتغير بين التوليدات، ولا تظهر غرف لم تُطلب.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

البرومبت يُبنى محلياً، فلا حاجة لأي مفتاح API للاستخدام الأساسي. متغير `GEMINI_API_KEY` في `.env.example` يلزم فقط لسكريبت Python المولَّد.

ميزات إضافية: حفظ المشروع كاملاً ككود Base64 واسترجاعه لاحقاً، وتصدير المخطط صورة PNG، وتراجع (undo) عبر متجر Zustand.

| المكتبة | الدور |
|---|---|
| React 19 + Vite 6 + TypeScript | الواجهة والبناء |
| Fabric.js 7 | لوحة الرسم والشبكة والتصدير |
| Zustand | الحالة وسجل التراجع |
| Tailwind CSS 4 | التنسيق |

## لماذا بنيته

احتجت تحويل توزيعات مكاتب حقيقية إلى صور 3D دون انحراف في القياسات.
