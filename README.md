# blueprint-3d-visualizer

[English](README.en.md)

**ترسم توزيع الغرف على لوحة 2D، ويطلع لك prompt معماري جاهز تلصقه في Google AI Studio — ونفس المخطط يعطي نفس النص دايماً.**

محرر مخططات يشتغل في المتصفح، يبني الـ prompt من إحداثياتك مباشرة، بدون أي نموذج لغوي بينه وبينك. مشروع من منطقتين بس يطلع منه prompt طوله 171 سطراً و10,742 حرفاً. الكود نفسه 3,796 سطر TypeScript في 12 ملفاً.

## المشكلة

نماذج توليد الصور ما تاخذ الوصف الحر على محمل الجد. تطلب 3 غرف ترسم لك 5. تحط مكتب في الزاوية الشمالية الغربية يطلع في النص. لو مررت المخطط على نموذج لغوي عشان يصيغ الـ prompt، يعيد كتابة القياسات على كيفه. النتيجة: كل مرة تولّد، يجيك توزيع غير مخططك.

## كيف يشتغل

1. ترسم المناطق على لوحة Fabric.js فيها شبكة، تسحب وتدوّر، والتدوير ينضبط على 15 درجة.
2. تختار لكل منطقة نوعها من 13 نوع غرفة، ونوع القاطع، وطراز الأثاث، والمميزات.
3. المحوّل يحسب لكل منطقة مركزها بالمتر، وحدودها، واتجاهها، وقطاعها (north-west / central / ...).
4. `promptBuilder.ts` — طوله 913 سطراً — يركّب الـ prompt النهائي من هذي البيانات نص عادي.
5. تنسخ الـ prompt للمحرك اللي تبيه، أو تصدّر المخطط PNG، أو تولّد سكريبت Python كامل.

يشتغل مع 5 محركات إخراج:

| المحرك | صيغة الإخراج |
|---|---|
| Nano Banana (Gemini 2.5 Flash Image) | prompt + سكريبت Python جاهز |
| Midjourney v6 | prompt مع أعلام `--ar --stylize --no` |
| DALL-E 3 | prompt نصي |
| Unreal Engine 5 | وصف مشهد archviz |
| Octane Render | وصف مشهد archviz |

### مخرج حقيقي

شغّلت المحوّل على مشروع من منطقتين (مكتب تنفيذي + غرفة اجتماعات) في مساحة 20×12 متراً:

## أهم قرار في التصميم

**المشكلة:** نموذج الصور يبتعد عن المخطط، والنموذج اللغوي الوسيط يزيد البُعد لما يعيد الصياغة.

**القرار:** أبني الـ prompt محلياً 100% — نفس المدخل يعطي نفس الناتج دايماً — وأكرر نفس التوزيع بـ 5 طرق داخل الـ prompt الواحد:

| التمثيل | ماذا يثبّت |
|---|---|
| وصف مكتوب لكل منطقة | النوع والأثاث والاتجاه والقطاع |
| مخطط أرضية ASCII | الموقع بالنسبة لباقي المناطق، كل خلية ≈ 0.4 متر |
| إحداثيات الزوايا الأربع | حدود كل منطقة بالمتر بالضبط |
| مصفوفة تجاور | وش المنطقتين اللي تتشارك جدار (سماحية 0.4 متر) |
| كتلة JSON | البيانات الخام كمرجع أخير |

**التكلفة:** prompt طويل (10,742 حرفاً لمنطقتين بس)، وملف بناء كبير (913 سطراً).

**العائد:** القياسات ما تتغير بين مرة وأخرى، وما تطلع غرف ما طلبتها.

## التشغيل

```bash
npm install
npm run dev
```

بعدها افتح `http://localhost:3000`.

الـ prompt يتبنى عندك على الجهاز، فما تحتاج أي API key للاستخدام العادي. متغير `GEMINI_API_KEY` في `.env.example` يلزمك بس لسكريبت Python المولّد.

فيه كمان: تحفظ المشروع كامل كنص Base64 وترجّعه بعدين، وتصدّر المخطط صورة PNG، وتراجع (undo) عبر Zustand store.

| المكتبة | الدور |
|---|---|
| React 19 + Vite 6 + TypeScript | الواجهة والبناء |
| Fabric.js 7 | لوحة الرسم والشبكة والتصدير |
| Zustand | الحالة وسجل التراجع |
| Tailwind CSS 4 | التنسيق |
